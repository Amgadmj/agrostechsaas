# Glossary (pt-BR ↔ EN)

| Term | Meaning |
|---|---|
| **AUL (Área Útil Líquida)** | Net plantable area: the output of Model M1 |
| **APP (Área de Preservação Permanente)** | Permanent preservation area (riverbanks, springs, hilltops, steep slopes); cannot be cultivated |
| **ARD** | Analysis-Ready Data (here: Sentinel-1 RTC L2) |
| **Barter** | Inputs paid with future grain; a trading company or input dealer finances the producer |
| **BDC** | Brazil Data Cube, INPE's analysis-ready satellite data platform with a STAC API |
| **CAR (Cadastro Ambiental Rural)** | Mandatory rural environmental registry. Code format `UF-IBGE7-HEX32` |
| **CENPROT** | Brazil's registry of protested debts |
| **CMN / BCB** | Conselho Monetário Nacional / Banco Central do Brasil |
| **COG** | Cloud-Optimized GeoTIFF |
| **CPR (Cédula de Produto Rural)** | Rural product note: a credit instrument backed by future production |
| **CRA** | Certificado de Recebíveis do Agronegócio (agribusiness receivables security) |
| **CRI (Cartório de Registro de Imóveis)** | Real-estate registry office, which holds the *matrícula* (title) |
| **Crédito rural** | Regulated agricultural credit, governed by the MCR |
| **dB / γ⁰ (gamma-nought)** | Radar backscatter coefficient, terrain-flattened, expressed in decibels |
| **Embargo (IBAMA)** | Federal environmental embargo on an area. It blocks rural credit |
| **FIAGRO** | Agribusiness investment fund |
| **Fuga de safra / grãos** | Grain diversion: harvested grain moved away from the creditor |
| **Gêmeo digital 3D** | 3D digital twin |
| **Gleba** | A land parcel or plot within a property |
| **IE (Inscrição Estadual)** | State tax registration |
| **INPE** | National Institute for Space Research |
| **Laranja** | Straw person or front entity |
| **MCR 2-9** | Manual de Crédito Rural, chapter 2, section 9: socio-environmental impediments |
| **MDF-e / NF-e** | Electronic cargo manifest / electronic invoice |
| **Minuta** | Draft (of a legal document) |
| **Passaporte de Crédito Rural** | AgrosTech's credit-readiness certificate for a property |
| **PAdES / LTV** | PDF Advanced Electronic Signatures / Long-Term Validation |
| **RJ (Recuperação Judicial)** | Judicial recovery: Brazil's Chapter 11 equivalent |
| **RL (Reserva Legal)** | Legal reserve: a mandatory share of native vegetation (20–80 % by biome) |
| **RTC** | Radiometric Terrain Correction |
| **S_clima** | AgrosTech's precipitation-based filter that refutes rain artefacts in M2 |
| **S_straw** | AgrosTech's straw-entity score (Shield-RJ vector 4) |
| **SAR** | Synthetic Aperture Radar |
| **Safra** | Crop season or harvest |
| **SEFAZ** | State tax authority |
| **SICAR** | National CAR system |
| **SIGEF / INCRA** | Land georeferencing certification system / land-reform institute |
| **SIRGAS 2000 / UTM 23S** | Brazilian geodetic datum / projected CRS (EPSG:31983) used in the surveys |
| **STAC** | SpatioTemporal Asset Catalog (API standard) |
| **TI / UC** | Terra Indígena (indigenous land) / Unidade de Conservação (protected area) |
| **Tutela cautelar** | Precautionary court relief |
| **VV / VH** | Co-polarised / cross-polarised radar channels |
